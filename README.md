## 🎯 Sobre el Proyecto

**Hundir la Flota** es una implementación completa y robusta del clásico juego de mesa de combate naval, diseñado para ejecutarse directamente en la terminal. El proyecto ha sido desarrollado aplicando buenas prácticas de programación estructurada, gestión de memoria y modularización en **C**.

Ideal para revocar nostalgias, echar unas buenas partidas en local y demostrar el poder de la programación de sistemas de la vieja escuela.

---

## ✨ Características Principales

- 🧩 **Estructura Modular:** Organizado mediante archivos de cabecera (`.h`) y código fuente (`.c`) separados limpiamente.
- 🎨 **Interfaz de Terminal Atractiva:** Tableros visuales interactivos diseñados para una experiencia de usuario fluida en CLI.
- ⚙️ **Lógica de Juego Robusta:** Control de disparos, validación de coordenadas, posicionamiento de flota y detección de barcos hundidos escritos puramente en C.
- 👥 **Desarrollo en Equipo:** Diseñado, codeado y testeado conjuntamente por 4 programadores.

## 🚀 Instalación y Ejecución

Sigue estos sencillos pasos para clonar el repositorio y compilar el juego en tu máquina:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/jgomezgarcia/hundir-la-flota.git](https://github.com/jgomezgarcia/hundir-la-flota.git)
   cd hundir-la-flota

    Compilar el código fuente (usando GCC):
    Bash

    gcc *.c -o hundir_la_flota

    Ejecutar el juego:
    Bash

    ./hundir_la_flota
